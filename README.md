# XIV Craft & Route Optimizer

FFXIV（ファイナルファンタジー14）向けのクラフター・ギャザラー支援Webツールです。
複数ジョブの同時製作・採集計画や、最安テレポ巡回ルートの最適化をサポートします。

## 主な機能
- **素材計算・管理**: 製作に必要な素材の自動集計
- **レシピ・素材登録**: API連携による自動補完・プレビュー確認・バリデーション機能
- **テレポルート最適化**: 効率的な巡回ルートの提示
- **採集時間表示**: 未知・伝説・刻限素材のET/LT（現実時間）連動タイマー
